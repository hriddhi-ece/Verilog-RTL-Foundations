# Multiplexer Architectures

This folder covers multiplexer designs using behavioral modeling.
* **Design:** 2-to-1 Multiplexer (`MUX_2x1.v`) using conditional `if-else` routing inside an `always @*` combinational block.
* **Verification:** Includes an exhaustive automated testbench (`tb_mux_2x1.v`) to validate select-line routing logic.
